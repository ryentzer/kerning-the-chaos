# Level-Up Guide

A Claude skill for learning a topic in depth. Ask Claude to help you "level up" on something, and it builds a multi-chapter interactive HTML guide: it starts from what you already know, includes live demos you can adjust, calls out the traps practitioners hit, and ends with a practice plan.

Both guides in `guides/` were made this way.

## Install

The skill is the single file `SKILL.md`.

- **Claude apps:** add it as a skill in Claude's settings (the exact menu location may change over time).
- **Claude Code:** copy this folder to `~/.claude/skills/level-up-guide/`.

The skill was written for one person's preferences (palette, tone, level of hedging). If you use it yourself, edit the background and design sections to match your own.
